# Weekbox

Weekbox is a simple weekly to-do app for planning a few things each day, without time slots or a complicated calendar.

**[Open Weekbox](https://weekbox-omega.vercel.app/)**

## Features

- Monday-to-Sunday weekly view with a card for each day.
- Add, edit, and delete tasks.
- Check off completed tasks with a faded, strikethrough style.
- Move between weeks or return to the current week with Today.
- Subtle highlighting for the current day.
- Tasks saved automatically in your browser with localStorage.
- Clean, minimal layout that works on desktop and phone.
- No login, accounts, or backend.
